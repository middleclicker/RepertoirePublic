Support

Get help with Repertoire.

Install on Android

Download Repertoire 1.0.0 for Android (Android 8.0 or later, 5.1 MB). Open the APK and follow Android’s installation prompts. If asked, allow your browser or file manager to install this app; you can turn that permission off after installation. This is a direct APK download; Repertoire is not yet on Google Play. The release page includes a SHA-256 checksum.

If you installed a debug build, save a backup or finish cloud sync before removing it. Android cannot update a differently signed debug build with the release APK, and uninstalling removes unsynced local data.

Contact us

Email cxy20052008@gmail.com for account access, cloud sync, deletion, catalogue corrections, accessibility issues, and bug reports. Include your app version, device model, and the steps that led to the issue. Never send your password, verification link, or authentication tokens.

Report public content

Open the musician's profile and choose Report or Block. To report another kind of public content, email us with the profile name and content details. See our Community rules for what is permitted and how moderation works.

Cloud sync

Open Profile → Cloud sync to see status and retry. Changes save on your device first. If two devices changed the journal, choose which complete journal to continue with. Contact us before choosing if you need help retaining information from both copies.

Delete your account

On Android, use Profile → Account → Delete account permanently. On iOS, use Profile → Delete account. If you cannot sign in, email us so we can help verify ownership and process your request. See our Privacy Policy and Terms of Use.
